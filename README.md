# Face Landing Page

A focused face landing page built in `projs/website`.

## Files

- `index.html` — homepage and layout
- `styles.css` — project styles
- `script.js` — front-end form handling

## Usage

Open `index.html` in a browser to view the site.

For development, serve the folder with any static server, for example:

```bash
cd "h:/O meu disco/sparklusa/projs/website"
python -m http.server 8000
```
